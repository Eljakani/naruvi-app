# README artwork

`naruvi-banner.png` is the final 1800 × 600 README banner. It combines the existing Naruvi logo (`public/brand/naruvi-otter-128-v2.png`), the app’s actual Geist font rendered to paths, and `banner-background.png`.

The background was created with the built-in image-generation tool. The logo and exact typography were composed locally. The earlier illustrated banner was discarded after the requested direction changed to a more restrained design.

## Background prompt

A refined minimal background for an open source productivity app README banner, very wide 3:1 landscape. Smooth warm off-white background, subtle broad translucent washes of muted sage and pale copper near the far right edge and bottom right, suggesting gentle water currents through soft light, sophisticated clean contemporary software identity. Left 75 percent almost plain warm off-white for large dark typography. Flat visual surface, no paper folds, no physical objects, no characters, no text, no logos, no sparkles, no grain, no hard outlines. Extremely restrained low contrast, airy calm professional aesthetic.

The final text uses Geist, as configured in `src/app/layout.tsx`. No font file is distributed in these assets.

The updated banner enlarges the lettering and adds a bold outline treatment to the Geist wordmark.
