# Code of conduct

Naruvi helps people through job searches, which are stressful enough. Keep this project a place where anyone can ask a question, report a bug or send a change without being made to feel small.

## Expected

- Be kind and assume good intent. Many contributors write in a second or third language.
- Critique code and ideas, not people.
- Accept that a maintainer may say no to a change, and explain why when you say no yourself.

## Not accepted

- Harassment, insults, slurs, or personal or political attacks.
- Sexual language or imagery, and unwanted attention of any kind.
- Publishing anyone's private information, including data from a CV, inbox or job search.
- Repeating any of the above after being asked to stop.

## Scope and enforcement

This applies to the issue tracker, pull requests, discussions and any other space that represents the project.

Report a problem privately to the maintainer through GitHub (the profile of the repository owner) rather than in a public thread. Reports are handled confidentially. The maintainer may edit or remove content, and warn or ban anyone who breaks these rules, for as long as they judge necessary.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
